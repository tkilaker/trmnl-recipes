# Väder nu

Today's weather for planning the day, in TRMNL's native style: temperature now,
feels-like, wind, the next twelve hours, three days, and one line saying when
rain or snow arrives in the next 48 hours.

Data: [Open-Meteo](https://open-meteo.com/) (no key), polled directly by TRMNL.
Set `Plats`, `Latitud` and `Longitud` in the plugin settings.

Built for mashups (`half_vertical`, e.g. next to a calendar) but every layout
renders the same block.
